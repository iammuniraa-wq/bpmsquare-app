Workforce rules by employment type — mock-up

Sample data only. Nothing is built. Switch the viewport and the screen; open a type, set a rule to Custom, Compare, Copy from, Apply; then look at what a Trainee and a supervisor see.
The idea: every employment type starts as Same as everyone (the workspace rules). A type only stores the rows an admin set to Custom. Rules are read per person at run time, so Apply is the save: everyone of that type is on the new rule the moment it is saved, with nothing to recompute. Holidays keep their own home (the Holidays screen) and now offer every configured type. A new type needs zero setup. Worked example, loaded: the BIM Trainee policy — weekly off None (Sunday is a training day), Paid leave, Sick and Comp off Not offered, and Leave on approval (an unpaid leave type) the one thing a trainee can request. Open Trainee to see it; Intern shows a lighter variant (Sick unpaid only).
