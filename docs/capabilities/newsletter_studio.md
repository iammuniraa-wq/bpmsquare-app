# newsletter_studio
status: experimental
plain: Design a newsletter once in English, add languages on top with AI translation you review, keep it as a template, and hand it to a campaign so each person gets their own language.
rules:
- English is written first for every newsletter; other languages are added on top and each translated block is marked until a person accepts it.
- A language can be sent only when every block has been reviewed by a person.
- The footer always carries the unsubscribe and preferences links and cannot be removed.
- Sending checks consent for each person and follows the workspace's email output setting, so a demo workspace never reaches a real customer.
- Clicks are tracked on signed links; opens are not tracked unless an admin turns that on.
- Switched on per workspace by a platform admin and needs Marketing campaigns; until then there is no menu item and no campaign page changes.
